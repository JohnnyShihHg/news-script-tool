# 查上網標記（書籤小工具）

在協作工具那一頁貼上 slug，告訴你文件裡那一則前面有沒有 `(勿上網)`。
**只讀不寫** —— 這支程式沒有任何寫回文件的路徑。

## 使用方式

1. 用瀏覽器打開 `install.html`，把裡面那顆按鈕**拖**到書籤列
   （書籤列沒出現：Chrome 按 `⌘⇧B` / `Ctrl+Shift+B`）
   拖不動就按「複製程式碼」，在書籤列按右鍵 →「新增頁面」，網址貼上
2. 開著協作文件那一頁，點書籤
3. 一行一個 slug 貼進去，按「查詢」（或 `⌘/Ctrl+Enter`）

再點一次書籤，或按 `Esc`，面板就收起來。面板可以拖著換位置。

## 判斷規則

| 顯示 | 意思 |
|---|---|
| ⛔ (勿上網) | slug 那行前面的括號裡有「勿」 |
| ✅ 無標記 | 命中了，前面沒有上網相關標記 |
| ⚠ 其他標記：… | 前面有別的標記，例如 `(版權問題)`、`(可上網)` |
| 標記後面的「部分命中：…」 | 你給的 slug 只蓋到文件那則的一部分，括號後面是文件裡的完整寫法 |
| ⚠ 文件裡找不到 | 整份文件沒有這個 slug（底下會列出只差一兩個字的，當成提示） |

- **只要這一筆有任何紅字（命中的、警示的、錯字建議裡的），一律排到最前面。**
  查不到但掃出相關勿上網的那種，跟直接命中勿上網一樣危險 —— 多半就是同事報錯了 ——
  所以不會被夾在中間讓人滑過去
- **其餘排序是：勿上網 → 其他標記 → 找不到 → 部分命中 → 無標記。** 要處理的排最上面，
  不需要你做任何事的「無標記」沉到最底下。同一級之內照你貼進去的順序
- **標記不一定要寫在括號裡。** `UP 蛋價續漲 SOT 18:00:00` 這種 slug 前面有裸標記的寫法
  照樣找得到；裸標記裡含「勿」一樣算勿上網
- **上傳者簽名（`UP`、`kk` 這類 4 字以內的英數字）一律忽略。** 那是每個人上傳後留的記號，
  人人不同、跟上網與否無關，所以不印出來，也不參與分組（同一則稿兩天由不同人上傳
  照樣併成 ×2）。濾掉簽名之後還剩下的裸字（例如中文的「暫停」）才會附在結果後面
- **空白一律忽略。** slug 本身含空白（`某某某 2100`）時，你打的跟文件寫的空白不一致
  照樣找得到；多打、少打、打兩個空白都行。邊界判斷仍然回到原始那一行上看
- **打錯字會給提示，但不會當成命中。** 找不到時會列出「只差一兩個字」的行，附上它的標記
  （`是不是這則：某某某 2100 ⛔ (勿上網) 差 1 字`），要不要採信由你決定。
  9 個字以上的 slug 容許差兩個字，短的只容許一個，3 個字以下不給提示
- **只給一段 slug 也查得到，但會標成「部分命中」。** 完整是 `女飛官211800`、同事只給
  `飛官21 1800` 這種很常見。命中的那一段要佔整個欄位的八成以上才認列，結果會把文件裡的
  完整寫法印出來讓你核對（`✅ 無標記 · 部分命中：女飛官211800`）。
  只有完全命中掛零時才會退而求其次找部分命中
- **完全命中才算。** slug 要從行首開始、後面緊接空白或行尾。查「蛋價」不會命中「蛋價續漲 SOT 18:00:00」
- **勿上網的判斷刻意放寬，寧可多報不可漏報。** 含「勿」的全算（`(勿)`、`(勿上)`、
  `(勿上網)`、`(勿上YT)`、`網勿`），不含「勿」的那一族也全算（`不上網`、`不上YT`、
  `不po網`、`不要上網`）。`(可上網)` 不會被誤擋
- **標記寫在 slug 後面也抓得到**（`蛋價續漲 (勿上網) SOT`），結果會註明「標記寫在後面」
- **只要文件裡有「跟你查的很像」而且是勿上網的稿，一律紅字警告** —— 不管你這次查到
  什麼、甚至完全查不到。前提是協作文件的標記是對的、會出錯的是輸入端（同事口頭報的
  slug、打錯的字、只給一段），所以這一關反過來做：輸入再怎麼歪，該擋的稿都要浮出來。
  相似度用編輯距離算，差四成以內就算相關。結果本身已經是勿上網時才不會再追加
- **全形半形都吃。** `（勿上網）` 與 `(勿上網)`、全形英數與半形、大小寫，折疊規則跟 `core/src/clean.rs` 的 `fold()` 一致
- **不管日期。** 同一則跨天重播出現多次就累計成 `×2`；標記不一樣則分行列出
- **`(抓新)`、`(抓)`、`(19)`、`(X/19)` 不算上網標記**，是重抓提示，會被當成透明的（對齊 App v0.3.7）
- 貼進來的 slug 自己帶標記（`(勿上網)蛋價續漲`）也查得到，會先剝掉再比

## 給同事

把 `bookmarklet.txt` 的**整行內容**傳給他們（群組貼一行就行），請他們在書籤列按右鍵 →
「新增頁面」，網址貼上。或是把 `install.html` 傳過去自己打開拖。

不需要安裝擴充功能、不需要開發者模式、不需要上架 Chrome Web Store，任何瀏覽器都能用，
包含 App 裡那個協作視窗。

## 改程式

```bash
node --test tools/collab-marker/tests/lookup.test.js   # 判斷邏輯的測試
node tools/collab-marker/build.js                      # 重新產生 bookmarklet.txt 與 install.html
```

| 檔案 | 內容 |
|---|---|
| `lookup.js` | 純邏輯：折疊、剝標記、分類、比對。沒有 DOM，可直接測 |
| `panel.js` | 介面：浮動面板、讀 `.ql-editor`、渲染結果 |
| `build.js` | 把兩支串成一行 `javascript:`，輸出 `bookmarklet.txt` 與 `install.html` |
| `tests/lookup.test.js` | 63 個案例，含全形括號、裸標記、完全命中、跨天累計、排序 |
| `tests/fake-collab.html` | 假的協作頁，手動試版面用（用 `http://` 開，`file://` 下有些瀏覽器會擋） |
| `bookmarklet.txt`、`install.html` | **產生物**，改完一定要重跑 `build.js` |

改完要發新版：重跑 build，把新的 `bookmarklet.txt` 內容再發一次，同事重新建立書籤。
協作工具本身很少改版，所以這件事不常發生。

## 限制

- 只看得到**目前頁面上已載入的文件**。文件還在同步、或根本沒開在協作頁，結果不準，
  面板會在底下用紅字提醒「找不到 .ql-editor」
- 認的是 `.ql-editor`（Quill 的編輯區）。哪天協作工具換掉編輯器，這裡要跟著改
